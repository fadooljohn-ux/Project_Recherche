# Pilot 1 sealed null evaluation result v0.1

The untouched 500-case evaluation passed all 13 gates using the locked
threshold without retuning. Two cases triggered, for a family-wise false
positive rate of 0.4%. The two-sided 95% Wilson interval is 0.11%–1.45%, so
both the 1% point-rate gate and 2.5% upper-bound gate pass.

The evaluation population remained disjoint from calibration. Null covariance
diagnostics, warnings, artifact integrity, memory, and storage passed. No
observed residual was searched.
